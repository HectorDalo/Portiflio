# Sistema de Cadastro de Clientes

Aplicação desktop desenvolvida em Python para gerenciar informações de clientes por meio de uma interface gráfica.

## Funcionalidades

- Cadastro de clientes.
- Listagem de clientes cadastrados.
- Edição de nome e telefone.
- Exclusão de clientes.
- Pesquisa de clientes.
- Validação de campos obrigatórios.
- Prevenção de nomes e telefones duplicados.
- Armazenamento persistente dos dados em JSON.

## Tecnologias utilizadas

- **Python** — linguagem utilizada na lógica do sistema.
- **Tkinter** — biblioteca utilizada para criar a interface gráfica.
- **JSON** — formato utilizado para armazenar os dados dos clientes.

## Como executar

1. Instale o Python no computador.
2. Abra a pasta do projeto.
3. Execute o arquivo responsável por iniciar a interface gráfica.

No terminal, execute o comando:

```bash
python interface.py
```


## Armazenamento de dados

Os dados são salvos em um arquivo JSON, permitindo que os registros permaneçam disponíveis quando o sistema for fechado e aberto novamente.

## Objetivo do projeto

Este projeto foi desenvolvido para praticar lógica de programação, funções, validação de dados, manipulação de arquivos e criação de interfaces gráficas com Python.
